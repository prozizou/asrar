# Changelog — Heures planétaires UI/UX

## Version proposée

### Mobile
- panneaux plus compacts ;
- temps actuel prioritaire ;
- timeline dense et lisible ;
- zones tactiles adaptées ;
- Jour/Nuit accessible pendant le scroll.

### Tablette
- meilleure largeur de lecture ;
- grille d'informations sur 4 colonnes quand l'espace le permet.

### Desktop
- largeur maximale portée à 1120 px ;
- informations générales et régents disposés côte à côte ;
- timeline centrale plus large.

### Alarmes
- remplacement visuel du carré `☐` par une cloche claire via CSS ;
- état actif marqué par une coche ;
- aucun changement de la logique native/Web existante.

### Robustesse UX
- focus clavier visible ;
- réduction des animations si le système le demande ;
- textes secondaires renforcés ;
- conservation des états erreur/GPS/chargement existants.
